GitHub Pages & Firebase Googleログイン 設定ガイド

完全無料でGitHub Pages上に独自のGoogleログイン付きクラウドPOSレジを構築する手順です。

1

Firebase Console で Google Auth を有効化

  1. Firebase Console でプロジェクトを作成します。
  2. Authentication > Get Started をクリックし、Google 認証プロバイダを有効にします。
  3. Firestore Database を作成し、テストモードで開始します。
  4. プロジェクト設定（歯車） > 「ウェブアプリを追加」し、発行される firebaseConfig JSONをコピーします。
2

承認済みドメイン（Authorized Domains）の追加 (最重要)

GitHub Pages（例: username.github.io）上でGoogleログインを動作させるために以下を設定します：

  • Firebase Console > Authentication > Settings > Authorized domains を開く
  • 「Add domain」をクリックし、username.github.io を追加登録する
3

アプリ画面での設定適用

画面右上の 「Firebase設定」 ボタンを押し、コピーした firebaseConfig JSONを貼り付けて「設定を保存」をクリックしてください。これでGoogleログインとリアルタイムFirestore同期がスタートします！
