GitHub Pages 公開 & Firebase 設定ガイド

このWebレジアプリを自分のGitHubアカウントで公開し、Firebaseと連携させる手順です。

1

Firebase プロジェクトの準備とGoogleログイン有効化

  1. Firebase Console にアクセスし、プロジェクトを新規作成します。
  2. 「Authentication」>「Sign-in method」を開き、Google ログインプロバイダを「有効」にします。
  3. 「Firestore Database」を作成し、テストモードでデータベースを開始します。
  4. プロジェクト設定（歯車アイコン）から「ウェブアプリを追加」し、発行された firebaseConfig のJavaScriptオブジェクトをコピーします。
2

GitHub Pages に無料公開

  1. GitHubで新しいリポジトリ（例: my-smart-pos）を作成します。
  2. このコード（index.html）をリポジトリのメインブランチ（main）にアップロードします。
  3. GitHubリポジトリの「Settings」>「Pages」を開きます。
  4. Source を「Deploy from a branch」にし、Branch を main / root に指定して Save します。
  5. 数分後、https://ユーザー名.github.io/my-smart-pos/ で公開されます。
3

GitHub Pages ドメインの認証ドメイン追加 (必須)

GoogleログインをGitHub Pages上で正しく動作させるため、Firebase Consoleの Authentication > Settings > 承認済みドメイン (Authorized domains) に、 お使いのGitHubドメイン（例: ユーザー名.github.io）を追加登録してください。
